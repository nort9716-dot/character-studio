# Character Studio App v2

نسخه کامل‌تر رابط PWA برای Character Studio.

این نسخه شامل:
- مدیریت چند Character مستقل
- Identity Anchor / Preservation Rules
- Pose Library تا Pose 27
- Outfit / Expression / Camera / Lighting / Environment libraries
- Autonomous Creative Prompt Engine
- ذخیره Characterها در Local Storage
- رابط مناسب موبایل و تبلت
- PWA و قابلیت نصب از مرورگرهای سازگار

نکته:
برای نصب به شکل App روی تبلت، فایل‌ها باید از یک آدرس HTTPS باز شوند (مثلاً یک هاست ساده). پس از بازکردن در مرورگر سازگار، گزینه Add to Home Screen / Install App نمایش داده می‌شود.

اتصال تولید واقعی تصویر نیازمند Backend امن و API key است و نباید کلید API داخل فایل‌های فرانت‌اند قرار گیرد.
